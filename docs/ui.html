布局与官方 App 对齐（§2.2.5）：输入源为只读徽章；解码徽章由音箱 0x68 状态实时驱动（05=有线 Hi-Res / 04=无线 Hi-Res / 00=标准，未知时不显示），断开时显示"—"；声音模式 = 0xD5/0xC4；自定义 EQ = 0x43/0x44（懒加载）；声学调校 = 0xC4 尾部 7 字节（M2，此为展开视图）。信号行：RSSI 换算为档位显示（≥−55 优秀 / −55~−70 良好 / −70~−80 一般 / <−80 弱），括号内保留 dBm 原始值。断开态：横幅提示 + 全部控件禁用，托盘同步切换状态。

05动效与交互规格

打开动画 150ms · scale .96→1 + 淡入 · 原点右下 滑条 拖动 150ms 节流合并下发 状态 通知推送驱动，无轮询刷新 折叠 瞬时展开 + 120ms 淡入，无高度动画 系统 跟随亮暗主题 · 尊重"减少动态效果" 徽章 解码状态由 0x68 实时驱动，非静态角标

06渲染性能预算（→ WPF 实现映射）

面板背景
系统 Mica/DWM backdrop（WPF-UI 应用级），不自绘模糊层；本页背景为近似模拟
飞出面板
窗口常驻 Hide()/Show()，二次打开 <50ms；EQ/声学调校内容懒加载
滑条
WPF-UI Slider 原生控件；拖动命令 150ms 合并（DispatcherTimer）后入命令队列
动画
仅 transform/opacity 合成动画；不动画布局属性；遵循系统减少动态效果
托盘图标
预生成多尺寸 .ico（4 状态 × 16–48），仅状态变更时更换，无逐帧重绘
RSSI
被动扫描（Passive），仅连接期间开启，更新 ≤1Hz
状态同步
BLE 通知推送为主，≥5s 轻量轮询仅保活对账；UI 绑定 SpeakerState 变更事件
主题
跟随系统亮暗即时切换（WPF-UI ThemeWatcher），令牌集中管理
整体
单实例；空闲内存目标 ≤60MB；自包含单文件 exe，无后台服务、无管理员权限
